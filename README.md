# Arena Breaker - Android

Builds an Android APK online with GitHub Actions (no Android Studio needed).

1. Create a free GitHub account and a new repository (private is fine).
2. Upload everything in this folder to it (drag and drop into the repo page).
   Make sure the `.github` folder is included.
3. Open the repo's **Actions** tab, choose **Build APK**, press **Run workflow**.
4. After a few minutes open the finished run, download **ArenaBreaker-apk** (a zip), unzip it.
5. Copy `app-debug.apk` to your phone and install it (allow "install unknown apps").

Controls: left stick = move (push to the edge to sprint), drag the right side = look,
FIRE / AIM / JUMP / SLIDE / RELOAD / NADE buttons, 1-4 = weapons, II = pause.
